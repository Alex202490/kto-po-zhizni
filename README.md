# КТО ПО ЖИЗНИ — чат / социальная площадка

Готовы разделы: Главная, Чат, Пользователи, Профиль. Есть верхняя панель с уведомлениями, кнопкой «Поддержать проект» и текущим пользователем; realtime-чат; список онлайн через Supabase Presence; аватар и обложка профиля; донатерские уровни; топ донатеров; рекламный блок.

## Донатерские уровни
- Бродяга — от 100 ₽
- Старший — от 500 ₽
- Блатной — от 5 000 ₽
- Авторитет — от 10 000 ₽

## Подключение Supabase
1. Создайте проект Supabase.
2. В SQL Editor выполните `supabase.sql`.
3. В Project Settings → API возьмите Project URL и anon/public key.
4. Вставьте их в `config.js`.
5. Service-role key в браузер не вставлять.

## Рекламный блок
В `config.js` есть:

```js
advertising: {
  image: "ССЫЛКА_ИЛИ_ИМЯ_КАРТИНКИ",
  link: "ПАРТНЕРСКАЯ_ССЫЛКА"
}
```

Если `image` оставить пустым, показывается стандартная заглушка «Здесь может быть ваша реклама». Если положить картинку рядом с сайтом, можно написать, например, `image: "ad.jpg"`.

## Оплата
Кнопка поддержки и четыре уровня уже сверстаны, но реальную оплату нужно подключать отдельно через выбранного платежного провайдера и серверный webhook. `donation_total` нельзя безопасно начислять только из браузера.


## Подписка, короны и светящиеся рамки
Разовая поддержка увеличивает `donation_total` и определяет уровень. При активной ежемесячной подписке (`subscription_active=true`) сайт дополнительно включает рамку: Старший — слабое серебряное свечение, Блатной — золотое, Авторитет — более толстое красно-золотое. Бродяга получает корону/статус без светящейся рамки.

Поля `donation_total` и `subscription_*` нельзя изменять из браузера. Их должен обновлять только серверный webhook после подтверждённого платежа.

## Увеличенный рекламный блок
Блок справа теперь 16:9 и целиком кликабельный. Положите баннер рядом с сайтом как `ad.jpg` (или поменяйте `advertising.image`) и вставьте рекламную/партнёрскую ссылку в `advertising.link` в `config.js`.
